## 最终效果

按照用户对第一版配色的反馈，将彩色窗口按钮和多色浅底卡片收敛为深绿与中性色。

- 使用 `morphicons@1.7.1` 和 Lucide 图标数据，统一导航、搜索、刷新、下载、上传、详情关闭、展开收起、设置和阶段状态等功能图标。悬停、键盘聚焦和状态切换触发短暂变形；系统减少动态效果设置生效。
- 窗口三键使用无底色线条，关闭键仅悬停时出现红色背景。最大化/还原依据真实原生窗口状态更新图标和选中状态；关闭沿用原有托盘后台运行行为。
- 模态设置窗口中通过 portal 将窗口控制保持在对话框顶层，详情弹层也不会遮住控制。窗口操作 IPC 仅接受受信任主 frame 和三种限定动作。
- 选中态使用深绿细边框、文字强调和勾选标记，减少大面积纯色及浅色色块；保留 `aria-current`，统计卡片及过滤按钮补充 `aria-pressed`。
- 在 Web/EXE 中随包包含 Morphicons、Lucide 及 Feather 的授权声明。
