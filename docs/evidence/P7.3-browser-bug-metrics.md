## Frozen slice semantics

`GET /api/v1/projects/:projectId/metrics/overview?from=<UTC>&to=<UTC>` is a read-only runtime API.
It requires canonical UTC timestamps with milliseconds and treats the window as `[from,to)`, bounded
to 366 days. `newBugCount` counts `bugs.created_at` in that window. `currentStateCounts` is the
current project-wide distribution and is intentionally independent of the creation window. All ten
frozen Bug states are returned in domain order, including zero counts. The response also returns the
same-project maximum `events.event_position` as `snapshotSequence`.

The storage worker computes the count and distribution from the QA Hub `bugs` projection; it does not
infer Bug creation from Relay, a second database or browser state. Active account/project/user
membership is required, and the existing singleton `SqliteStorageWorker` remains the only database
adapter used by the API process.
