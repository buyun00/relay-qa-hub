not changed. The App was built only by this repository's Gradle project with `minSdk=35`,

## One critical failure

The capture session was stopped and runtime inspection confirmed there was no active projection.
A new session was requested and the system MediaProjection dialog was cancelled. The App showed:

```text
Capture unavailable: screen-sharing permission denied. Ordinary defect entry remains available.
```

`dumpsys media_projection` remained empty for the App, and the data root still contained exactly
one Bug and one capture. The temporary API was stopped and `adb reverse` was removed after the
proof; 4319 was no longer listening.
