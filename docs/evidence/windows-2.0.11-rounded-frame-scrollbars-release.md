## 变化

原桌面描边为直角，Windows 圆角裁切后底部两角缺少连续弧线。本次普通窗口使用 8px 圆角描边，并由真实窗口状态驱动最大化/还原时的直角/圆角切换。桌面外层底色与标题栏一致，内部画布保留浅色。描边保持 2px 和 `pointer-events: none`。

应用内滚动区域统一使用绿色圆角滑块：轨道宽/高 10px，透明边距留出约 6px 的可见滑块，悬停与拖动时加深颜色，移除原生上下箭头。覆盖页面、侧栏、弹窗、多行输入框及横向滚动区域；滚轮、拖动和键盘滚动仍由浏览器处理。移除了会覆盖 Chromium 自定义圆角的局部 `scrollbar-width: thin`，仅为不支持 WebKit 滚动条选择器的浏览器保留标准属性回退。
