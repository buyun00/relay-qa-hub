## 界面变化

按用户选定的 C 方案，将侧栏品牌区与内容区顶部合为跨窗口全宽的 60px 深绿标题栏。Q 图标、连接灯、QA Hub 名称、原始 BaLOOT GO 标识组成一个紧凑品牌组，搜索、刷新和 Windows 原生窗口按钮在同一行。移除重复的品牌副标题、项目名称及页标题。

侧栏导航与内容区从标题栏下方开始，内容独立滚动。搜索保留原有工作台范围与 Ctrl+K 行为；其他页面沿用各自上下文和刷新行为。窗口控件预留区依据原生覆盖层宽度计算。详情和设置弹窗出现时暂停标题栏拖动区域，确保弹窗按钮可点击。
