## Informative blocker found and repaired

The first real owner update returned `500 ERR_SQLITE_ERROR`: the prior `comment.created #2` Event had
advanced the Bug aggregate sequence without advancing Bug resource version, while `bug.updated` still
used `bug.version + 1` and collided at sequence 2. The failed transaction rolled back, leaving the Bug
at version 1. Commits `728aa55` and `4108ce9` now derive Bug Event aggregate sequence from the current
per-aggregate maximum for both field updates and the adjacent ready transition, while resource version,
payload versions, outbox aggregate version and Bug CAS remain `bug.version + 1`. The retried browser
transaction succeeded as `bug.updated #3`. Final Luna/max review reported Blocker/High=`0/0`.

## 2026-08-26 bounded Relay outbox scheduling follow-up

The real loopback Relay delivery path now uses the durable outbox attempt counter instead of a fixed
30-second retry. It parses bounded delta/date `Retry-After`, retries only network/timeout and
`408/425/429/5xx` failures with exponential delay, moves permanent client/protocol/evidence failures
directly to `dead`, and caps retryable delivery at eight claims. The storage claim also blocks a later
aggregate version while any earlier version for the same destination remains non-`sent`, including a
dead letter, so an operator-visible failure cannot be silently bypassed by a later continue action.
