## 问题与修复

原更新器进入 `ready` 后直接跳过后续检查，安装时也直接使用此前缓存的安装包。客户端长期运行且渠道连续发布时，会先安装过时版本，重启后再发现更新，表现为逐版升级。

本次让已下载状态继续检查签名清单；安装入口统一等待正在执行的检查，再重新确认渠道最新版。下载结束后再次读取清单，发现新发布则换成新的完整安装包。最多连续检查三次；渠道持续变动或网络、签名、哈希校验失败时保留当前客户端并允许重试，不回退安装缓存中的旧包。

相同签名的缓存包通过大小及 SHA-256 复核后直接复用，丢失或损坏时重新下载。检查与安装串行执行，重复安装点击共用一次操作；同一版本的就绪通知在一次客户端运行中只提示一次。
