## Result

The Web detail loader no longer treats React memory as the source of truth for the human workflow. It now calls:

```text
GET /api/v1/bugs/:bugId/human-workflow
```

The read model follows the Bug's active RepairAttempt and Verification pointers. A Build is returned only through the exact immutable `build_repair_links` / BuildRequirement relationship; it is never inferred from a matching commit alone.

On reload, hash deep-link, or selecting the Bug again, the Web restores the persisted Attempt, linked Build and Verification. A recovered `running` Attempt can continue delivery without starting twice, and a recovered `requested` Verification can start without creating a duplicate.
