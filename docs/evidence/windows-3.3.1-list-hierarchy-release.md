## 最终行为

根据用户对 3.3.0 的反馈，恢复承担信息区分作用的颜色，保留克制的窗口控制与卡片选中态。

- 移除覆盖原有优先级、进度和人员头像颜色的样式。工作台 P0 红、P1 橙、P2 蓝、P3 绿、P4 灰，恢复原有色块和状态标签。
- 每条事项补充修复人与关闭人；当前动作人保留头像、姓名和角色。窄桌面窗口保留人员列，将更新时间放在进度下方，长姓名省略后可查看完整提示。
- 五个导航图标分别为绿、蓝、紫、橙、青，选中时保留各自颜色。工作台为独立分区网格，总览为表格，两者默认与交互形状均有区别。
- 最小化始终显示水平横线，移除下载箭头形状。其余窗口控制保持原有简洁线条和真实原生窗口状态反馈。
