# OZDQP 项目名称与 Logo

当前项目的显示名称为 `OZDQP`。API 启动时通过现有 `MOBILE_SCOPE` 配置同步项目和所属账户的显示名称；项目 ID `10000000-0000-4000-8000-000000000004`、项目键 `LOCAL` 及既有 Bug、人员、成员关系保持原有身份。同步仅在名称不同且身份校验通过时更新，重复启动不会增加版本号。

Web 与 Windows 客户端共用的顶部项目位置显示游戏 Logo，原图位于 `apps/web/src/assets/ozdqp-logo.png`。该图片随应用打包，可用于桌面客户端的本地页面；替代文本和悬浮提示均为 `OZDQP`。其他项目仍显示各自名称，项目选择列表及 Android 项目名称使用 API 返回的 `OZDQP`。

Logo 使用用户提供的原始 PNG，SHA-256 为 `229d7d9baca79561ae08e653409c319f869b2ac787f18d34c010c77d009ea9c6`。平台自身的 Relay QA Hub 品牌、安装目录和协议名称保持原有定义，避免影响已安装客户端与升级路径。历史证据中的当时名称保留原文。

Windows 1.2.7 包含此次界面更新。验证覆盖已有项目名称同步、身份不变、其他项目不受影响、名称同步幂等以及 Web 页面显示。
